# Návrh 01 — čistý web s modrým akcentem

První dokončený design autoškoly. Hlavní součástí je [statický web](staticky-web/index.html), který odpovídá zveřejněnému [náhledu](https://autoskola-jedovnicky-navrh.svobodamatyass.chatgpt.site/). Ve složce [wordpress-tema](wordpress-tema/autoskola-jedovnicky/) je zdroj vlastní WordPress šablony připravené pro tento směr.

Statický web lze zobrazit lokálně přímo otevřením `staticky-web/index.html` nebo pomocí `python -m http.server` ze složky `staticky-web`.

WordPress šablona zatím neprošla zkouškou v klientově instalaci. Podrobnosti a omezení jsou v jejím vlastním README.
