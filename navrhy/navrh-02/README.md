# Návrh 02 — minimalistický černobílý směr

Samostatný mobilní návrh připravený od nuly. Jeho základ tvoří systémové písmo, černá a bílá, klidná hierarchie, skutečné fotografie a několik jemných přechodů při scrollování. HTML, CSS i JavaScript jsou nové a nejsou odvozené od Návrhu 01.

Funkční neveřejný náhled: https://autoskola-jedovnicky-navrh-02.svobodamatyass.chatgpt.site/

Náhled spustíte otevřením web/index.html nebo lokálním serverem z této složky:

    python -m http.server 8028 --directory web

Použité logo a fotografie pocházejí z podkladů pro autoškolu. Sociální profily nejsou přidány, protože jejich adresy dosud nebyly spolehlivě potvrzené. Hodnocení není uvedeno.
